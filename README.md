# Node.js Tutorial

## About

This repository documents my **Node.js learning journey**, covering fundamental concepts, server-side programming, backend development, and hands-on practice.

The goal of this repository is to build a strong foundation in Node.js through consistent coding practice, understand how backend applications work, and gradually progress toward building real-world backend applications and REST APIs.

## Topics Covered

* Introduction to Node.js
* Node.js Runtime and Architecture
* Modules and `require` / `import`
* Built-in Node.js Modules
* NPM and Package Management
* `package.json`
* File System (`fs`) Module
* Path Module
* HTTP Module
* Creating Web Servers
* Request and Response Handling
* Asynchronous Programming
* Callbacks
* Promises
* `async/await`
* Events and Event Emitters
* Environment Variables
* Express.js
* Routing
* Middleware
* REST APIs
* Error Handling
* Backend Project Development
